# GitHub.io Storybook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add app-local Storybook for `apps/github.io` so the abstract Astryx app shell can be viewed and iterated visually from an iPad.

**Architecture:** Use Nx's React Storybook generator to install/configure Storybook for the existing Vite React app, then keep Storybook configuration under `apps/github.io/.storybook`. Split the current one-file shell into small React components and add static CSF stories that import the same global styles as the app.

**Tech Stack:** Nx `23.0.2`, pnpm via Corepack, React `19.2.7`, Vite `^8.1.4`, Storybook React/Vite through Nx, Vitest, Testing Library, ESLint, Astryx.

## Global Constraints

- Work in the linked worktree at `.worktrees/storybook-github-io`.
- Configure Storybook for `apps/github.io` only.
- Storybook host must be `0.0.0.0`.
- Storybook port must be `4400`.
- Do not create a shared UI/component library.
- Do not deploy Storybook.
- Do not add real portfolio, resume, project, or contact content.
- Do not redesign the app shell beyond the structure needed for storyable components.
- Do not add browser automation or visual regression testing in this setup.
- Use pnpm for package and Nx commands.
- Prefer Nx generators for Storybook configuration.
- Stage explicit paths only.
- Use conventional commits.

```tsx
export interface TopBarProps {

export function TopBar({ brandLabel, navItems }: TopBarProps) {
  return (
    <header className="top-bar">
```

```tsx
import { navItems, placeholderSections } from './app-shell.data';
import { HeroIntro } from './hero-intro';
import { PlaceholderSection } from './placeholder-section';
import { SiteFooter } from './site-footer';
import { TopBar } from './top-bar';

export function AppShell() {
  return (
    <Theme theme={neutralTheme}>
      <div className="app-shell">
        <TopBar brandLabel="App Shell" navItems={navItems} />

        <main className="page">
          <HeroIntro
            eyebrow="Page Shell"
            title="Generic Layout Skeleton"
            body="A constrained single-page structure for future portfolio content."
          />

          <div className="section-list" aria-label="Placeholder sections">
            {placeholderSections.map((section) => (
              <PlaceholderSection key={section.id} {...section} />
            ))}
          </div>
        </main>

        <SiteFooter label="Footer Region" />
      </div>
    </Theme>
  );
}
```
