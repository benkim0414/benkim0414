# GitHub.io React App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a basic Vite React app named `github.io` under `apps/github.io` for the GitHub Pages user-site root.

**Architecture:** Use Nx generators to add React/Vite support and scaffold the app, then replace the generated starter UI with a static Astryx-based app shell. The app has no routing, API calls, persisted state, deployment workflow, or real portfolio content.

**Tech Stack:** Nx 19.5.6, pnpm, React, Vite, Vitest if generated by Nx, Astryx core, Astryx neutral theme.

## Global Constraints

- Add a Vite React application named `github.io`.
- Place the app under `apps/github.io`.
- Use the repository's pnpm workflow.
- Use Astryx as the UI/design-system foundation.
- Render a generic single-page app-shell skeleton.
- Do not add GitHub Actions or GitHub Pages deployment automation.
- Do not add Playwright or a new e2e test setup.
- Do not add real personal profile, resume, project, or contact content.
- Do not add a light/dark mode toggle in the first version.
- Prefer Nx generators for adding React support and creating the app.
- Stage explicit paths only when committing.
- Use conventional commit messages.

---

## File Structure

- Modify `pnpm-workspace.yaml`: include `apps/*` alongside the existing `packages/*`.
- Modify `package.json`: add Nx React/Vite-related dev dependencies and Astryx runtime dependencies through pnpm commands.
- Modify `pnpm-lock.yaml`: dependency lockfile updates from pnpm.
- Modify `nx.json`: generator/plugin updates if Nx adds them.
- Create `apps/github.io/`: generated Vite React app project.
- Modify `apps/github.io/src/main.tsx`: import Astryx CSS and mount the app.
- Modify `apps/github.io/src/app/app.tsx`: render the generic app-shell skeleton.
- Modify `apps/github.io/src/app/app.css` or `apps/github.io/src/styles.css`: add minimal layout styling using Astryx CSS variables.
- Modify generated app test files only if the generated starter test expects text that is removed.

References checked while writing this plan:

- Nx React generator docs: `https://nx.dev/docs/technologies/react/generators`

- Astryx theme docs: `https://astryx.atmeta.com/docs/theme`

### Task 3: Build the Generic App-Shell Skeleton

**Files:**
- Modify: `apps/github.io/src/app/app.tsx`
- Modify: `apps/github.io/src/styles.css`
- Modify: `apps/github.io/src/app/app.spec.tsx`, if Nx generates it and its assertion text no longer matches

**Interfaces:**
- Consumes: Astryx `Theme` wrapper from Task 2.
- Produces: Static single-page generic app shell with no personal content and no runtime state.

- [ ] **Step 1: Replace the temporary app body**

Edit `apps/github.io/src/app/app.tsx` to:

```tsx
import {Theme} from '@astryxdesign/core';
import {neutralTheme} from '@astryxdesign/theme-neutral';

const navItems = ['Overview', 'Work', 'Notes'];

const sections = [
  {
    id: 'overview',
    label: 'Section 01',
    title: 'Content Region',
    body: 'Reserved space for future profile content.',
  },
  {
    id: 'work',
    label: 'Section 02',
    title: 'Content Region',
    body: 'Reserved space for future project content.',
  },
  {
    id: 'notes',
    label: 'Section 03',
    title: 'Content Region',
    body: 'Reserved space for future contact content.',
  },
];

export function App() {
  return (
    <Theme theme={neutralTheme}>
      <div className="app-shell">
        <header className="top-bar">
          <a className="brand" href="/" aria-label="Home">
            App Shell
          </a>
          <nav className="nav" aria-label="Primary navigation">
            {navItems.map((item) => (
              <a key={item} href={`#${item.toLowerCase()}`}>
                {item}
              </a>
            ))}
          </nav>
        </header>

        <main className="page">
          <section className="intro" aria-labelledby="intro-title">
            <p className="eyebrow">Page Shell</p>
            <h1 id="intro-title">Generic Layout Skeleton</h1>
            <p>
              A constrained single-page structure for future portfolio content.
            </p>
          </section>

          <div className="section-list" aria-label="Placeholder sections">
            {sections.map((section) => (
              <section
                className="content-section"
                id={section.id}
                key={section.label}
              >
                <p className="eyebrow">{section.label}</p>
                <h2>{section.title}</h2>
                <p>{section.body}</p>
              </section>
            ))}
          </div>
        </main>

        <footer className="footer">Footer Region</footer>
      </div>
    </Theme>
  );
}

export default App;
```
