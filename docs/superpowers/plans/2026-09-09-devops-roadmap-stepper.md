# DevOps Roadmap Stepper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the `/roadmap` page's React Flow visualization with a static, evidence-aware Astryx Stepper while preserving the existing roadmap component.

**Architecture:** Upgrade the coordinated Astryx packages to 0.5.4, add canonical one-sentence descriptions to the existing roadmap model, and render the skill-inventory projection through a new `DevOpsRoadmapStepper`. The Stepper remains non-interactive: numbered vertical steps use semantic success for evidence and disabled styling for unsupported topics, while the old `DevOpsRoadmap` remains untouched.

**Tech Stack:** React 19, TypeScript 5.9, Astryx Core/Theme/CLI 0.5.4, StyleX, Vitest, Testing Library, Storybook 10, Nx, pnpm

**Spec:** `docs/superpowers/specs/2026-09-08-devops-roadmap-stepper-design.md`

## Global Constraints

- Work only in the linked worktree on `feat/devops-roadmap-stepper`; do not edit the main checkout.
- Use `@astryxdesign/core`, `@astryxdesign/theme-neutral`, and `@astryxdesign/cli` version `^0.5.4` together.
- Use official Astryx `Stepper` and `Step` with `orientation="vertical"`, `density="balanced"`, and `indicator="number"`; do not recreate their UI.
- Render all 22 existing roadmap topics in their existing order.
- A step has evidence when it has a skill token, certification, or covered concept; evidence uses semantic success, while no evidence is disabled/upcoming.
- Use `activeStep={-1}` as the no-current sentinel only if focused tests against Astryx 0.5.4 confirm that it renders no `aria-current="step"`; otherwise stop and return to design.
- Keep descriptions to one original, neutral sentence of roughly 10–20 words informed by roadmap.sh.
- Reuse neutral `SkillToken` links, `CertificationCitation`, and Astryx `Token` for evidence.
- Preserve `DevOpsRoadmap`, `DevOpsRoadmapNode`, their React Flow behavior, tests, and stories.
- Preserve the `/roadmap` route, page heading, banner, attribution, and surrounding layout.
- Do not add interaction, filters, collapsing, grouping, phases, or topic reordering.
- Stage explicit paths only and commit every independently reviewable task with a conventional commit subject.

- [ ] **Step 3: Implement the minimal Stepper component**

Create `devops-roadmap-stepper.tsx` with this structure:

```tsx
import {HStack, VStack} from '@astryxdesign/core/Layout';
import {Step, Stepper} from '@astryxdesign/core/Stepper';
import {Token} from '@astryxdesign/core/Token';
import {spacingVars} from '@astryxdesign/core/theme/tokens.stylex';
import * as stylex from '@stylexjs/stylex';
import type {ReactElement} from 'react';

import {CertificationCitation} from '../certifications/certification-citation';
import {skills} from '../skills/skill-list.data';
import {getSkillDetailPathForSkillName} from '../skills/skill-route';
import {SkillToken} from '../skills/skill-token';
import {devOpsRoadmapSkillInventoryNodes} from './devops-roadmap-skill-inventory.data';
import type {DevOpsRoadmapItem} from './devops-roadmap.types';

export interface DevOpsRoadmapStepperProps {
  readonly label?: string;
  readonly items?: readonly DevOpsRoadmapItem[];
}

const NO_ACTIVE_STEP = -1;

const styles = stylex.create({
  evidenceList: {
    display: 'flex',
    flexWrap: 'wrap',
    gap: spacingVars['--spacing-2'],
    margin: 0,
    padding: 0,
    listStyle: 'none',
  },
  evidenceItem: {
    display: 'inline-flex',
    maxWidth: '100%',
    listStyle: 'none',
  },
});

function hasVisibleEvidence(item: DevOpsRoadmapItem): boolean {
  const evidenceSkillTokens = item.evidenceSkillTokens ?? item.skills ?? [];

  return Boolean(
    item.certifications?.length ||
      evidenceSkillTokens.length ||
      item.coveredRoadmapConcepts?.length,
  );
}

function StepEvidence({item}: {readonly item: DevOpsRoadmapItem}) {
  const evidenceSkillTokens = item.evidenceSkillTokens ?? item.skills ?? [];

  return (
    <VStack gap={2}>
      {item.certifications?.length ? (
        <HStack
          as="ul"
          aria-label={`${item.title} certifications`}
          wrap="wrap"
          xstyle={styles.evidenceList}
        >
          {item.certifications.map((certification, index) => (
            <li key={certification.title} {...stylex.props(styles.evidenceItem)}>
              <CertificationCitation {...certification} number={index + 1} />
            </li>
          ))}
        </HStack>
      ) : null}
      {evidenceSkillTokens.length ? (
        <HStack
          as="ul"
          aria-label={`${item.title} evidence skills`}
          wrap="wrap"
          xstyle={styles.evidenceList}
        >
          {evidenceSkillTokens.map(skill => (
            <li key={skill} {...stylex.props(styles.evidenceItem)}>
              <SkillToken
                href={getSkillDetailPathForSkillName(skill, skills)}
                label={skill}
                variant="neutral"
              />
            </li>
          ))}
        </HStack>
      ) : null}
      {item.coveredRoadmapConcepts?.length ? (
        <HStack
          as="ul"
          aria-label={`${item.title} covered concepts`}
          wrap="wrap"
          xstyle={styles.evidenceList}
        >
          {item.coveredRoadmapConcepts.map(concept => (
            <li key={concept} {...stylex.props(styles.evidenceItem)}>
              <Token color="gray" label={concept} size="sm" />
            </li>
          ))}
        </HStack>
      ) : null}
    </VStack>
  );
}

export function DevOpsRoadmapStepper({
  label = 'DevOps roadmap',
  items = devOpsRoadmapSkillInventoryNodes,
}: DevOpsRoadmapStepperProps): ReactElement {
  return (
    <Stepper
      activeStep={NO_ACTIVE_STEP}
      density="balanced"
      label={label}
      orientation="vertical"
    >
      {items.map((item, index) => {
        const hasEvidence = hasVisibleEvidence(item);

        return (
          <Step
            description={item.description}
            indicator="number"
            isDisabled={!hasEvidence}
            key={item.id}
            label={item.title}
            status={hasEvidence ? 'success' : undefined}
            step={index}
          >
            {hasEvidence ? <StepEvidence item={item} /> : null}
          </Step>
        );
      })}
    </Stepper>
  );
}
```

Adjust import paths or only documented prop names if the installed 0.5.4 CLI shows a difference. Preserve the public interface and behavior above.
